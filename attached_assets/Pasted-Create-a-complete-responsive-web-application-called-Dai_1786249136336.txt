Create a complete responsive web application called **“Daily Expense Management System”**.

This is a **simple college project for manually managing daily expenses**. The application must start with a **completely new user account with zero data**.

## IMPORTANT — NEW USER / EMPTY SYSTEM

When the website is opened for the first time:

* Do NOT show any sample expenses.
* Do NOT show any sample income.
* Do NOT show any sample transactions.
* Do NOT show ₹30,000 income.
* Do NOT show ₹12,450 expenses.
* Do NOT show 24 transactions.
* Do NOT show fake chart data.
* Do NOT show fake category amounts.
* Do NOT show a Total Balance card.
* All dashboard values must initially be **₹0** or **0**.
* Charts should show an appropriate empty state such as **“No expense data yet”**.
* Recent Transactions should show **“No transactions yet”**.
* Categories should initially have no spending amounts.
* The user starts entering their own data manually.

The application should use **localStorage** so that once the new user adds expenses, the information remains after refreshing the browser.

# 14. LOCAL STORAGE

Use browser localStorage.

The initial localStorage state must be empty:

```text
expenses = []
```

Do not seed the application with dummy data.

When the user adds an expense:

```text
expenses = [new expense]
```

When the user deletes an expense, remove it from localStorage.

When the page reloads, retrieve the user's saved expenses.
